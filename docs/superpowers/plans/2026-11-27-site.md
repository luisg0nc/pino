# pino.luisg.me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page site for pino at `https://pino.luisg.me/`, copied from torno's site and cut down, with pictures
made from a hidden window on a copy of `simple-blinker`, deployed by GitHub Pages.

**Architecture:** `site/` holds a static page (`index.html`, `assets/site.css`, `assets/site.js`, the mark as SVG,
`CNAME`, `.nojekyll`). `app/scripts/build-site.mjs` copies the fonts and the pictures into `site/` at deploy time.
The pictures come from a new group in pino's own `app/e2e/shots.spec.ts` (the only spec that may take pictures) and
are cropped by `app/scripts/site-images.py` into `docs/images/`. `.github/workflows/pages.yml` deploys `site/`.

**Tech Stack:** static HTML/CSS/JS, Node 22 script, Playwright + Electron (hidden window), Python 3 with Pillow (run
through `uv run --with pillow`), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-27-site-design.md`

**Torno source:** copy from `luisg0nc/torno` at `main` commit `8086e7cac36981150e41ffd342160f749a712c07` with
`gh api repos/luisg0nc/torno/contents/<path>?ref=<sha> -q .content | base64 -d > <pino path>`, then adapt with the
Edit tool. Never retype torno code. Never run anything inside `~/projects/torno`.

## Global Constraints

- Every copied file gets an entry in `shared-from-torno.json` (`adapted`, one line of what changed); `pnpm -C app exec vitest run src/manifest.test.ts src/tornoSync.test.ts` passes.
- The page loads nothing from another host (no CDN, no web font service, no analytics).
- Colours and faces are pino's: values from `app/src/renderer/styles/tokens.css`, Instrument Sans and Martian Mono from `@fontsource` (copied by `build-site.mjs`). The family names may also be written in `site/assets/site.css`; extend whatever test holds "family names only in shared/fonts.ts and tokens.css" to allow that one file, saying why.
- The mark is pin one: the SVG is drawn from `renderer/ui/pinOne.ts` (generate it, do not hand-draw a different one).
- English, sentence case, no em dashes or en dashes anywhere in the page or docs. Copy is short and plain; claim nothing pino has not done (it has not been run with the real Claude Code: no "what goes well" list, no numbers about speed or quality).
- Every Electron launch goes through `e2e/launch.ts` (`PINO_TEST=1`, hidden window, temp home, offline). Pictures only through `helpers.ts` `capture` (one per launch), never `page.screenshot()`, never a resize of a window with a board drawn: use `PINO_TEST_SIZE`.
- Nothing personal in a picture: no home path, no other board, no chat of Luis's. The board copy lives under the run's temp folder.
- Edits with the Edit tool only (no sed, no inline Python writing files). pnpm, never npm.
- Commits: plain messages, no attribution trailer.

## Review Focus

- `PINO_SITE_BOARD` unset, or set with `PINO_SHOTS` unset or inside the repo: the site group skips, and `pnpm test:e2e` in CI stays green (assert it in the spec's skip condition, as the existing group does).
- The copied board carries its `.pino/chat`, `session.json` or `marks`: the copy must leave them out, and the title bar must show the temp workspace's plain name, not `/home/...`. The spec asserts the title text does not contain `homedir()`.
- A picture referenced by `index.html` that `build-site.mjs` does not copy: `site.test.ts` fails (copied from torno's "names only files that are there or that the Pages build copies").
- Dark theme: the page's `prefers-color-scheme: dark` swaps the hero picture and colours; `site.test.ts` checks the dark tokens equal the window's dark tokens.
- `prefers-reduced-motion`: any reveal or motion in `site.js`/`site.css` is off (torno's test "reduces motion when asked").
