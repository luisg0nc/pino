A workbench for making circuit boards with Claude Code.

You point at the board, and Claude Code edits the Python file behind it. On every save, pino builds that file into a KiCad project and runs the checks.

New and early. Linux only. Apache-2.0.

The loop

The board is a Python file, board.py. pino has no tools for placing parts or drawing tracks by hand.

  1. You describe the board, or mark it

    Point at a part, draw an arrow to where it should go, or sketch the way a track should run. Each mark can carry a note.

  2. Claude Code edits board.py

    pino sends your marks with your next message as exact references: the part, the pad, the net. Through pino's tools, Claude can look at the board, measure it and read the checks.

  3. The engine builds it

    On save, it runs the file, writes a KiCad 10 project, and runs KiCad's electrical and design rule checks along with pino's own.

  4. pino draws it and reports back

    The window shows the new build. Claude is told what changed and what failed.

The window

Four tabs on one board, with the Claude Code session beside them.

What it is for

Small boards

Two or four layers, made for up to about a hundred parts.

JLCPCB parts

Name a part by its LCSC number. pino looks up its stock, its price, and whether JLC calls it basic or extended.

Fab files

Gerbers, drill files, a BOM and a CPL (placement) file, which you upload to JLCPCB yourself. Check every part in JLC's placement preview before you pay.

Linux

pino runs on Linux only. It is developed on Arch with Wayland.

What you need and how to run it

You need

  • Linux
  • Node.js 22.12 or later, and pnpm
  • uv, which runs the engine
  • KiCad 10 with its libraries, for the checks and the routing
  • Claude Code on your PATH, logged in

Then

git clone https://github.com/luisg0nc/pino.git
cd pino
pnpm install
scripts/pino ~/boards

pino checks what it needs on its first screen and says what is missing. The first route installs the router into a cache in your home folder, once.
